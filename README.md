# Переводчик (Android)

Сам определяет язык текста:
- любой иностранный язык → **русский**;
- русский → язык, выбранный внизу экрана (по умолчанию английский).

## Движки
- **Google** — бесплатно, без ключа, перевод прямо во время набора.
- **Офлайн** — перевод на телефоне без интернета (ML Kit). В настройках отмечаешь нужные языки и скачиваешь (≈30 МБ на язык). Без сети приложение само переключается на офлайн.
- **Свой ИИ** — любой API (OpenAI-совместимый или Anthropic): в настройках указываются адрес, ключ и модель. Стиль перевода и разбор нюансов. Всё хранится только на телефоне.

## Удобства
- Пункт **«Переводчик»** в меню выделения текста в любом приложении и в меню «Поделиться».
- **Голосовой ввод**: нажал микрофон — говоришь, нажал ещё раз — запись закончена и сразу идёт перевод. Кнопка рядом переключает язык диктовки (RU ↔ язык перевода).
- **Автообновление**: при запуске приложение проверяет последний релиз в этом репозитории, скачивает APK и открывает системный установщик. Работает только для публичного репозитория.
- Озвучка, копирование, «поделиться», обратный перевод, история.
- Тёмная тема по системной настройке.

## Сборка
Каждый push в `main`/`master` (или ручной запуск во вкладке **Actions → Build APK → Run workflow**) собирает APK и публикует его во вкладке **Releases**. В хранилище Actions ничего не загружается (ни artifacts, ни кэш). Хранятся 5 последних релизов.

APK подписан ключом `app/release.jks` из репозитория, поэтому новые версии ставятся поверх старых без удаления.
